Privacy Policy for SportsTicker: Card Prices

Last updated: August 13, 2026

What this extension does

shows sports card median eBay market prices like a stock ticker, with tracked searches and price-history sparklines, in a toolbar popup.

Data collection

This extension does not collect any personal data. It has no accounts and no server. Nothing is sold or shared.

Local storage

Your tracked searches and their last seen prices are stored locally using the storage API. The eBay access token you paste into settings is stored only on your device and is sent only to eBay's API when fetching prices.

Network

The popup requests eBay's public Browse API (api.ebay.com) to search listings and fetch prices, using the token you provided. These requests include your IP address, as any web request does. The extension sends nothing else anywhere.
