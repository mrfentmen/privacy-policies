Privacy Policy for Api Tester

Last updated: August 11, 2026

What this extension does

Api Tester is a tool for sending HTTP requests to API endpoints you enter, and for testing AI API keys such as those from AI providers. You decide every request: the URL, method, headers, and body.

Data collection

This extension does not collect any personal data. It has no accounts, no login, and no server of its own. It never sends traffic on its own and never runs in the background.

What is sent and where

Every network request is started by you and goes only to the URL you typed or selected. The request contains only the method, headers, and body you supplied, including any API key you pasted. The extension itself never sends anything anywhere. When you use the AI provider key checker, the request goes directly to the provider you chose with the key you entered.

Local storage

Your saved presets, provider settings, and any API keys you chose to save are stored in your browser's local storage on your own device. They never leave your browser and are cleared when you clear browser data or uninstall the extension. Stored keys are kept only if you leave the save option on.

Host access

Cross origin requests to hosts you have not allowed yet require you to grant access first. The extension asks before sending to a new host.
